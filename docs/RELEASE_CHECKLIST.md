# Release checklist — not yet signed off

- [ ] Install and run on a clean Windows 10 device.
- [ ] Install and run on a clean Windows 11 device.
- [ ] Verify signed installer and publisher identity.
- [ ] Verify company registration, unique company workspace and administrator account.
- [ ] Verify login, logout, expiry, password reset and session revocation.
- [ ] Verify staff invitation expiry, single-use token and role assignment restrictions.
- [ ] Attempt cross-company data access against every API endpoint and background job.
- [ ] Attempt unauthorised role actions directly against APIs.
- [ ] Verify company data backup and restoration from backup.
- [ ] Verify subscription checkout, webhook signature, retries, duplicate webhook handling, grace period and cancellation.
- [ ] Verify email/WhatsApp consent, delivery, failure logging and retries.
- [ ] Verify offline cache encryption, queued writes, conflict resolution and reconnection.
- [ ] Verify application update, rollback and uninstall behaviour.
- [ ] Verify data export and audit history.
- [ ] Complete user acceptance testing with representative staff roles.
